# 주차 설명 영상과 발표 초안

WBS-092 / REQ-009·012·013 / SPEC-006 v0.2.0, CR-091·093.
문서 초안과 과제 전용 수정 채팅은 WBS-097 / `ASSIGNMENTS.md`를 따른다.

## 사용 흐름

- 과목을 연 뒤 위쪽 주차 메뉴 → **이 주차 설명 영상 만들기**. 선택 주차의 자료·전사·메모와 과목 공통 자료를 읽는다. 다른 주차의 본문은 영상 입력으로 가져오지 않는다.
- 과제 → **AI 제출용 초안 미리보기** → **발표 초안 · PPTX/PDF**. 누적 과목 원본으로 별도 슬라이드 계획을 만든다. 문서 초안의 채팅 수정이 기존 슬라이드 계획에 자동 반영되는 기능은 아니다.
- 초기 입력에서 사용 가능·누락·제외·문자 수를 확인한다. 과제 안내는 제외할 수 없다. 50만 자 초과는 요청 전에 막으며 사용자가 범위를 줄여야 한다. PDF의 그림·도표와 읽을 수 없는 자료는 누락으로 표시한다. 누락/제외가 있으면 부분 생성 동의가 필요하다.
- **계획 만들기**는 공식 Claude Code 구독 runner로 내용만 생성한다. 대본·슬라이드·출처·미확인 사항을 확인한 뒤 검토 체크와 **파일 만들기**를 선택한다. 검토한 정확한 계획만 출력한다.
- 영상은 설정에서 사용자가 직접 저장한 HeyGen API 키·음성이 필요하다. 대본만 HeyGen Starfish API에 전송하고 별도 API 크레딧을 사용한다. 키 인증·샘플 재생은 실제 생성 성공을 보장하지 않는다. 현재 목록의 `available_engines`가 Starfish를 허용하지 않으면 선택/출력을 막는다. 공급자 자동 전환이나 유료 자동 재시도는 없다.
- 로컬 도구 준비는 유료 API를 호출하지 않는다. 영상에는 고정 HyperFrames·Node·Chrome·FFmpeg가 필요하다. PPTX PDF는 실행 중인 Docker Desktop에서 별도 LibreOffice 이미지를 준비한다. 변환은 네트워크 없이 실제 PPTX를 읽고, 원본 PPTX가 변하면 완료 처리를 거절한다.
- 완료한 MP4 또는 PPTX·PDF를 열거나 Finder에서 확인한다. 이 도구는 LMS에 첨부·제출하지 않는다. WBS-058 실제 제출과 음성 실검증은 최신 사용자 지시로 보류다.

## 저장·취소·복구

앱 userData의 `data/artifact-workflows`에 계정/과목 SHA 경로별 새 실행 폴더와 비공개 index를 둔다. source 증거는 원문 대신 hash·선택/누락 범위를 보존한다. renderer는 파일 경로·실행 명령·API 키를 받지 않는다. 생성된 내용은 로컬에 보존되며 Git에 저장하지 않는다.

같은 계정·과목에서 한 작업만 진행한다. 창을 닫거나 주차를 바꿔도 시작한 작업은 유지되며 해당 화면을 다시 열어 상태를 확인하거나 취소한다. 다른 주차에서 진행 중이어도 취소 버튼을 제공한다. 계정 변경·앱 종료는 실행을 중단한다. 재시작한 미완료 계획은 interrupted이며 자동으로 모델/TTS를 재호출하지 않는다. 새 계획 생성은 명시적인 새 요청이다. 이미 발생한 API 비용은 취소로 되돌리지 못할 수 있다. 완료 파일은 저장 hash를 검사하고 수정된 파일을 정상 원본으로 열지 않는다.

## 검사

`pnpm --filter @learningxxx/desktop-host run check`, UI check, learning-artifacts check, `docker compose run --rm tools`.

`node --experimental-strip-types apps/desktop/host/scripts/artifact-local-smoke.ts /private/tmp/<새 폴더>`는 합성 계획의 실제 PPTX→PDF만 검사한다. 모델/TTS 호출은 없다.

개발 앱 실행 파일에 `--artifact-voice-smoke=/private/tmp/<새 폴더> --catalog-only`를 전달하면 저장된 키로 목록만 검사한다. `--catalog-only`를 생략하면 고정 공개 한국어 문장 한 개에 **실제 유료 TTS 한 번**과 MP4 렌더를 실행하므로 별도 명시 실행에만 사용한다. 모델 생성 성공의 증거가 아니다. 다른 앱 인스턴스를 정상 종료한 뒤 실행한다. 자격 증명이나 공급자 오류 원문은 보고서·하위 프로세스·로그에 쓰지 않는다.

실제 수행 결과·리뷰와 미완료 검증은 `docs/pm/reviews/WBS-092.md`에 기록한다.
