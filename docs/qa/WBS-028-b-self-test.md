## 직접 따라 할 시나리오 (20분 내외)

1. `run-app.sh`로 앱을 켜고 과목을 고른 뒤 오른쪽 **전사** 탭의 엔진 카드가 "준비됨"인지 본다. 아니면 내려받기 아이콘으로 준비한다(공개 모델 약 5GB, 한 번만).
2. **녹음** 탭에서 1~2분 녹음하고 멈춘다. 전사 탭에 그 녹음의 전사가 "대기 → 진행 중(실제 진행률) → 완료"로 바뀌는지 본다. 10분 녹음이면 약 3~5분 걸린다.
3. 전사 탭에서 문장 하나의 시간을 눌러 그 지점부터 재생되는지 본다.
4. 3분 이상 녹음을 하나 더 만들고 전사가 "진행 중"일 때 앱을 끈다(터미널 Ctrl-C). 다시 켜고 약 10분 안에(작업 임대 만료 후) 같은 녹음이 다시 전사되어 완료되는지, 전사본이 둘로 늘지 않는지 본다.
5. 녹음 탭의 온라인 강의 목록에서 영상 하나를 받고, 받은 원본이 열리고 자동 전사되는지 본다(강의에 직접 MP4가 없으면 "지원하지 않는 형식"으로 남는 것이 정상).
6. 채팅에서 전사본을 첨부해 "이 강의 요점 정리해줘"를 보낸다. 요약은 사용자가 요청할 때만 만들어진다.

결과는 위 표에 날짜와 한 줄로 적는다. 문제는 재현 절차·기대/실제·심각도(P0 데이터 손실·세션 교차, P1 기능 오류, P2 우회 가능)로 남긴다.

## 기능별 작동 설명

### 녹음 (REQ-007, WBS-023)
- 흐름: 녹음 시작 → 마이크 권한·여유 공간 확인 → 16kHz 모노 소리를 약 2초마다 디스크에 바로 기록 → 멈추면 AAC(.m4a) 원본으로 확정 → 자동 전사 등록.
- 데이터: `~/Library/Application Support/@learningxxx/desktop-host/data/media/originals/`(원본, 내용 해시 이름). 원본은 사용자가 요청하지 않으면 지우거나 덮어쓰지 않는다.
- 실패 복구: 강제 종료 시 다음 시작 때 저장된 부분까지 "복구됨"으로 확정. 공간 부족·잠자기·마이크 분리는 멈추고 저장.

### 온라인 강의 영상 (REQ-008, WBS-024)
- 흐름: 사용자가 고른 강의만 학교 계정 세션으로 Commons의 직접 MP4를 받음 → 크기·MP4 구조·해시 확인 후 원본 확정 → 자동 전사 등록.
- 실패 복구: 서명 만료·연결 중단은 최대 3회 처음부터 다시 받음. DRM·스트리밍 전용 강의는 우회하지 않고 이유를 표시.

### 자동 전사 (WBS-025·027·053, ADR-003)
- 실행 위치: 이 Mac의 앱 전용 가상환경에서 Qwen3-ASR 1.7B(8GB 이하 Mac은 0.6B). 녹음을 외부로 보내지 않는다.
- 흐름: 원본 확정 → 같은 내용·같은 엔진이면 기존 작업 재사용(중복 없음) → macOS `afconvert`로 16kHz WAV → 과목 자료 제목을 용어 힌트로 넘겨 전사 → 단어 시각으로 읽기 좋은 구간을 만들고 환각 문구·연속 반복 제거 → 전사본 저장.
- 자동/수동: 전사는 자동, 요약·보정은 사용자가 요청할 때만.
- 실패 복구: 일시적 실패는 30초·2분 뒤 자동 재시도(최대 3회). 엔진이 없으면 즉시 실패로 멈추고, 엔진이 준비되면(이번 실행에서 준비했거나 앱 시작 시 이미 준비돼 있으면) 자동으로 다시 돈다. 전사 중 앱이 꺼지면 작업 임대(10분)가 끝난 뒤 다시 실행한다.
