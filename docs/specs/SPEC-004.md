## 전체 MVP에 포함
REQ-007/008. B 단계에서 대면 강의 녹음, 온라인 강의 영상 다운로드, 원본 재생·보존, 자동 전사를 구현한다. 실시간 번역은 별도 C 단계다. 전사 텍스트와 요약은 다른 산출물이며 전사 완료가 자동 요약을 유발하지 않는다.

## 녹음 흐름
과목/강의 선택 → macOS 마이크 권한 → 녹음 시작 → 경과 시간·저장 상태 → 중지 → 원본 확정 → 전사 작업 enqueue. 권한 거절은 설정 안내와 재시도 경로를 제공한다. 중간 청크를 안전하게 저장하여 강제 종료 시 복구 가능한 부분을 표시한다. 디스크 부족·기기 변경·절전/잠자기·중지 실패를 다룬다.
Recording: id, courseId, startedAt, durationMs, sourceDevice, status, originalAssetId. 원본은 사용자 요청 없이 삭제하거나 덮어쓰지 않는다.

## 온라인 영상 흐름
LMS의 사용 권한이 있는 해당 강의 소스 확인 → 메타데이터 정규화 → 다운로드 job → 완성 검증 → 원본 저장·열기 → 전사 enqueue. 일반적인 다운로드 흐름만 계획에 활용한다. 기존 khu-lecture-recorder skill의 코드·설계 세부·구현 방법은 구현 단계에서 참고하지 않는다. DRM/권한 제한 우회는 설계하지 않고 불가 사유를 표시한다.
일시적 URL·세션 만료 시 인증된 새 소스를 획득해 재시도한다. 받은 일부 파일을 정상 완료로 표시하지 않는다. 오디오 추출용 중간 파일은 원본과 구분하고 정책에 따라 정리한다.

## 전사 파이프라인
Job: id, sourceAssetId, engineVersion, parametersHash, status, progress?, attempt, errorCode, outputAssetId?.
queued → running → succeeded / failed / cancelled. source hash+engine+parameters를 멱등 키로 사용한다. 새 엔진으로 재전사하면 이전 결과를 별도 버전으로 유지한다. 워커 종료 시 처리 중 lease 만료 후 안전하게 재개하며 결과 중복을 방지한다.
TranscriptSegment: startMs, endMs, text, confidence?; 화자 분리는 MVP 필수로 가정하지 않는다. 원문 타임스탬프와 연결하여 해당 구간을 재생한다. 수정 전사본은 원본 엔진 출력과 구분한다.

## 엔진·비용·위치
결정(2026-11-02, ADR-003): Qwen3-ASR 1.7B를 각자의 Mac에서 MLX로 실행하고 녹음을 외부로 보내지 않는다. 개선은 용어 힌트·규칙 정리(자동)와 요청 시 Claude 보정본(별도 버전)으로 한다. 아래는 결정 전 기준으로 남긴다.
STT 엔진과 Mac/서버 실행 위치는 아직 선택하지 않았다. 짧은 실제 표본으로 한국어·전문용어·긴 침묵·노이즈·처리시간·메모리·디스크를 비교한다. AI 채팅 구독 로그인 요건은 별도 STT 서비스의 무료 사용을 뜻하지 않는다. 기본 검토는 로컬 처리 후보이며 유료 외부 STT가 필요하면 비용·전송 범위를 새 결정으로 명시한다.

## UX와 실패
녹음과 다운로드가 완료되면 사용자가 다시 버튼을 누르지 않아도 전사가 시작된다. 앱이 꺼져 있던 동안 생긴 원본도 다음 실행에 누락 없이 큐에 등록한다. 진행률을 알 수 없으면 불확정 진행을 표시하고 가짜 %를 만들지 않는다. 실패는 원본을 보존하며 재시도한다. 사용자가 원본을 열고 전사를 채팅에 첨부할 수 있다.

## 수용 조건
녹음 종료→원본 재생→전사 생성의 연결을 실제 Mac에서 검수한다. 다운로드 중단→재시도→완성 검증→전사도 검수한다. 자동 전사는 중복 작업을 만들지 않는다. 전사에서 타임스탬프 클릭 시 해당 원본 구간으로 이동한다. 엔진 선택 회의에서 표본과 합격 수치를 확정하고 결과를 QA에 남긴다.



## CR-053 · 녹음·전사 정리와 엔진 준비 복구

현재 로컬 Qwen3-ASR MLX와 0.4.4 런타임을 유지한다. Apple Silicon Mac, 8GB 이하는 0.6B/그 외 1.7B 및 ForcedAligner 0.6B. 앱 전용 stt/.venv·stt/hf의 실행 파일·런타임 버전·모델 config/가중치를 확인한다. 환경→의존성→모델→검증 단계가 실제 성공해야 ready이며 설치 실패를 숨기지 않는다. 공개 모델 설치만 다운로드하고 실제 오디오 전사는 오프라인 캐시만 사용한다. 설치 단일 실행/취소/종료 정리, 전사 중 설치 잠금을 제공한다. 준비 성공 후 현재 계정의 ENGINE_UNAVAILABLE 작업을 멱등 재시도하며 오래된 엔진 작업의 재시도는 현재 엔진 구성을 쓴다. 원본·기존 전사 보존과 계정/과목/체크섬 검증을 유지한다. 합성 음성 검증은 장시간 실제 강의 품질을 증명하지 않는다.

## CR-101 · 구간 전사와 녹음 중 전사

긴 오디오는 약 5분 구간으로 나눠 전사한다. 목표 시각 ±8초 안의 가장 조용한 100ms에서 끊고, 30초보다 짧은 마지막 조각은 앞 구간에 붙인다. 구간마다 엔진 프로세스를 따로 실행하고, 결과를 이어 붙여 하나의 전사본으로 저장한다. 엔진 프로세스는 앱 전체에서 한 번에 하나만 실행하고, MLX 버퍼 캐시 상한은 0이다. 끝난 구간 결과는 내용 해시로 보관해서 일시정지·앱 종료·실패 뒤 재시도할 때 그 다음 구간부터 이어 간다. 보관한 결과는 전사본이 저장되면 지우고, 끝나지 않은 것은 14일 뒤 지운다.

녹음 중에는 녹음이 한 구간만큼 쌓일 때마다 그 구간을 떼어 전사한다. 전사가 켜져 있고, 일시정지 상태가 아니고, 엔진이 준비된 경우에만 한다. 녹음을 멈추면 남은 꼬리만 전사하고 구간 결과를 합쳐 원본의 전사본으로 만든다. 같은 과목 용어 문맥을 쓰고, 원본을 처음부터 다시 전사하지 않는다. 앱이 강제로 종료돼도 다음 실행에서 이어 간다. 녹음 화면에 저장된 길이와 전사된 길이를 함께 보여 준다. 한 구간보다 짧은 녹음은 기존처럼 녹음이 끝난 뒤 전사한다.

전사가 실패하면 엔진이 남긴 오류의 마지막 줄을 300자 이내로, 파일 경로를 빼고 작업에 남겨 화면에 보여 준다. 근거 측정은 docs/qa/WBS-101-window-experiment.md에 있다(전체 대비 차이 4.3%, 차이는 표기·조사 수준, 최대 메모리 11.9GB→8.3GB).
