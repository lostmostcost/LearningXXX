# WBS-027 · 원본과 자동 전사 연결

REQ-007/008, SPEC-004, ADR-002/003. 각자의 Mac 안에서 실행하며 서버 전송이나
자동 요약을 추가하지 않습니다. 023/024/025/026 및 046의 큐 경계 수정을 연결합니다.

## 직접 사용할 순서

1. 해당 계정으로 자료를 수집하고 과목을 엽니다. 전사 엔진이 아직 없다면 저장소에서
   `services/transcriber/setup.sh`를 실행해 앱 전용 환경을 준비합니다. 시스템 Python에
   직접 설치하지 않습니다. host는 userData/stt의 Python·모델 캐시를 사용합니다.
2. 녹음을 시작하고 멈춥니다. 확정된 원본은 별도 전사 버튼 없이 큐에 들어갑니다.
   앱 재시작 시 중단 녹음을 복구하고, 확정됐지만 큐 등록 전 종료된 원본도 등록합니다.
3. 온라인 강의는 ‘온라인 강의 확인’ → 접근 가능한 강의 선택 → ‘원본 다운로드’를
   누릅니다. 직접 MP4 원본만 지원하며 URL이나 인증 정보를 입력/표시하지 않습니다.
   완료 원본/목록 저장 후 자동 전사합니다. 다운로드 취소, 실패 후 재선택이 가능합니다.
4. 원본과 전사 화면에서 실제 상태·타임스탬프를 봅니다. 실패한 전사는 재시도합니다.
   엔진 준비가 필요하면 설치 후 재시도합니다. 재전사 엔진 설정이 달라졌다면
   현재 설정으로 원본을 재등록하는 재시작/목록 복구가 별도 버전 job을 만듭니다.
5. 선택한 전사 버전의 ‘이 전사 복사’로 복사한 뒤 원하는 채팅에 직접 붙여넣고
   요청합니다. 자동 전송/자동 요약이나 다른 세션으로의 자동 전달은 없습니다.

## 데이터와 복구

- 녹음 원본/복구 정보: 기존 `data/media/originals/`, `data/media/recordings.json`.
- 계정별 미디어 카탈로그: `data/media/accounts/<accountKey>/catalog.json`.
- 다운로드 원본: 같은 계정 폴더의 `video-originals/<hash-prefix>/<hash>.mp4`.
- 큐와 결과: 계정 폴더의 `transcription/jobs.json`, `transcription/transcripts/<id>.json`.
- 카탈로그는 원본을 먼저 기록한 후 큐 등록합니다. 재시작 때 재등록해 누락을 복구하고,
  같은 내용·엔진·파라미터는 같은 job을 재사용합니다. 동일 바이트의 원본 ID 별칭은
  과목 목록에서 해당 ID로 투영해 타임스탬프와 결과가 끊기지 않게 합니다.
- 중단 다운로드는 재시작 시 실패/중단으로 표시하고 사용자가 새 소스로 재시도합니다.
  반쯤 받은 파일은 완료 원본/전사 대상으로 쓰지 않습니다. 다운로드 원본이 확정됐지만
  큐 등록이 실패한 경우 원본 성공 상태를 보존하고 다음 목록 조회/시작에 큐를 복구합니다.
- 재생/엔진 실행 전 크기·SHA-256·경로를 검사합니다. 손상 원본과 카탈로그는 덮어쓰지
  않습니다. 계정 변경은 이전 다운로드/워커를 중단하며 목록·재생·재시도는 현재 계정의
  과목으로 제한합니다. 미디어 카탈로그 오류가 앱 창 자체의 시작을 막지 않습니다.

## 검증 범위와 제한

컨테이너의 통합 회귀는 실제 RecordingService의 합성 PCM→WAV 확정 콜백,
합성 MP4 다운로드→자동 큐, 누락 job·재시작·중복 방지·계정/과목 경계·원본 손상을
가짜 엔진과 함께 확인합니다. 실제 강의/녹음/자격증명은 저장소에 넣지 않습니다.
실제 Mac 마이크/학교 영상/MLX 모델 전사·재생의 기능 자가 테스트는 WBS-028에서
기록해야 하며, 컨테이너 통과를 그 결과로 주장하지 않습니다.

앱 내 Blob 재생은 256 MiB까지입니다. 더 큰 원본은 메모리로 전부 가져오지 않고
‘시스템 플레이어로 열기’로 재생합니다. 큰 원본의 앱 내 타임스탬프 seek는 지원하지
않으며 시스템 플레이어에서 직접 이동합니다. HLS/DASH·DRM 우회는 지원하지 않습니다.
채팅 연결은 명시적인 버전별 복사/붙여넣기이며 준비 첨부 목록에 자동 등록하지 않습니다.
다운로드 강제 종료 시 남은 `.part`는 사용하지 않으며 자동 삭제하지 않습니다.
전사 속도/정확도, 8GB Mac 성능, 긴 강의의 실제 메모리 사용은 이 검사에서 미측정입니다.

검사: `docker compose run --rm tools`, 새 clone에서 같은 명령,
`python3 scripts/check_scope.py WBS-027 origin/main`, `git diff --check origin/main`.
