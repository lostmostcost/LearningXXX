## 선행 사용자·CLI 시나리오

과목 목록 열기 → 과목 선택 → 자료 주차/기타 메뉴에서 녹음 링크가 없고 PDF/기존 동영상은 남는지 확인 → 좌측 녹음·전사 → 주차 선택 → 원본 선택 → 해당 전사 확인. 주차 전환 시 이전 전사/원본 해제, 빈 주차·미정 주차·명시 재배정 후 선택 일치, 좁은 화면의 실제 스크롤 접근을 확인한다. 구현 전에 Ready WBS와 CR에 이 시나리오를 기록했다. debug는 실제 메뉴 순서이고 assist는 기존 media 탐색 단축만 사용할 수 있다. 일반 select/버튼/scroll은 공통 renderer에서 이미 지원하므로 새 명령·상태 주입·raw IPC는 추가하지 않는다. 같은 기존 layout-smoke 경로를 확장한다.

## 구현과 단계별 자체 리뷰

1. **분류 모델**: recording-weeks.ts의 mediaWeekGroups와 기존 메타데이터/계약을 검토했다. 현재 과목의 LMS 주차 순서 및 recording.weekId로 분류한다. 날짜로 소속을 추측하지 않는다. 다른 과목 녹음·파생 파일을 제외하고 삭제된 주차/소속 녹음이 없는 원본은 미정에 남긴다. 영상은 명확히 일치하는 LMS 주차가 있을 때만 연결한다. 빈 주차·동일 원본 재배정·타 과목 메타데이터·모호한 영상 주차를 모델 검사로 확인했다. 입력 배열을 변형하지 않고 그룹별 새 배열을 만든다.
2. **실제 화면**: MediaLibrary/RecordingPanel과 TranscriptPanel 호출자를 검토했다. 전체/각 LMS 주차/주차 미정, 원본 개수와 주차별 optgroup, 제목·녹음 시각을 표시한다. 원본을 지운 경우에도 전사 접근은 보존한다. 사용자가 필터를 바꾸면 controlled 원본 선택도 같은 이벤트에서 해제해 이전 전사가 남지 않게 했다. 새 저장/재배정으로 선택한 원본이 다른 그룹으로 이동하면 필터가 따라가고 source key를 유지하도록 파생 필터를 사용해 불필요한 player unmount를 피했다. 녹음 singleton과 저장/전사 서비스는 변경하지 않는다. 목록 오류/재시도/전사/원본 삭제 경로는 기존 host 및 UI 처리를 재사용한다.
3. **자료 경로 제거**: App.tsx의 주차 트레이에서 녹음·중첩 녹음·미분류 녹음 링크와 사용하지 않는 RecordingFile 컴포넌트를 제거했다. PDF/과제/공지와 온라인 영상 재생은 유지한다. 자료 영상 선택이 숨은 녹음 화면의 원본 선택을 바꾸지 않도록 연결도 제거했다. 새 빈 주차 판단은 자료와 동영상만 사용한다. 과제 언급 등 기존 참조는 녹음·전사 화면으로 이동하며 전체 녹음/전사 뷰어를 다른 주 화면에 추가하지 않았다.
4. **회귀와 시각 확인**: fake-host에 schema-compatible 합성 두 주차 원본·전사를 추가해 목록만 비어 있는 시나리오 통과를 피했다. 실제 LMS label인 2주차 (보강)를 유지했다. CLI는 공개 snapshot의 option을 읽어 선택한다. 초기 수용 검사에서 화면 아래의 전사문은 읽히지 않아 실패했다. 내부 상태를 읽지 않고 실제 scroll 명령으로 노출한 뒤 확인하도록 시나리오를 보완했다. 넓은 2주차/전사 PNG와 좁은 주차/원본 선택 PNG를 직접 열어 검토했다.

매 단계 실제 diff와 주변 호출자·과목 경계·선택 해제/재배정·삭제된 원본/주차·로딩/실패·좁은 화면을 리뷰하고 해당 모델/타입/CLI 검사를 실행한 뒤 재검토했다. 마지막 기준 main 전체 diff에서 범위/요구의 추가 차단 결함은 발견하지 않았다. 테스트 통과를 무결함 보장으로 쓰지 않는다. 원본 재생 위치의 실제 미디어 연속 재생까지 검증했다고 주장하지 않으며 source key 유지와 선택/전사 보존 범위를 확인했다.

## 사용 방법과 경계

녹음·전사 탭 → 주차(전체/각 주차/미정) → 원본 선택으로 전사와 원본을 확인한다. 같은 제목도 녹음 시각으로 구분한다. 주차를 바꾸면 원본을 다시 고른다. 미정 녹음은 기존 주차 지정 기능으로 명시적으로 옮긴다. 파일/전사를 자동 삭제·이동하지 않으며 원본 지움 표시는 기존 전사 보존 계약을 따른다. 기존 온라인 강의 영상은 자료 탭에서도 재생할 수 있고 녹음 목록/전사 뷰어는 녹음·전사 화면에 둔다.

이미 열어 둔 사용자의 실제 앱 세션을 강제 종료·새로 고침하지 않았다. 새 빌드는 앱을 재실행하면 반영된다. 사람 자가 QA 사실을 만들지 않으며 이번 routine 작업은 적절한 검사·자체 리뷰·로컬 병합 후 완료한다. 최종 SHA·scope·claim 해제 결과는 원본 Notion WBS에 기록한다.
