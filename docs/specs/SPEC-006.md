# SPEC-006 · 주차 설명 영상·과제 초안

Source: https://app.notion.com/p/40dbd7ec20cd81e38167e782400993d1
Approved CR: https://app.notion.com/p/40dbd7ec20cd814dbf14ed63c9ed2a69
Snapshot: 2026-11-04 · v0.1.0 · CR-091 사용자 직접 승인. 구현 상태는 WBS 참조.

REQ-012: 주차 자료(PDF 텍스트·전사·메모·공지)를 검토하여 대본·출처·장면을 만들고 HeyGen TTS API 내레이션과 로컬 HyperFrames MP4로 저장한다.
REQ-013: 과제 상세의 안내·첨부·누적 과목 자료를 검토하여 PDF 문서 또는 편집 가능한 PPTX와 그 PPTX를 변환한 제출용 PDF 초안을 생성한다. 원본 산출물과 출처·요구사항 대응·미확인 사항을 보존한다.

내용 생성은 기존 공식 Claude 구독 실행을 주입한다. 음성 API는 별도 명시 설정이며 API에는 대본만 전달하고 Claude 인증을 전달하지 않는다. 무료/다른 공급자로 자동 전환하지 않는다. 사용자 요청 때만 실행하며 과금 작업 자동 재전송 없음.

입력은 host가 고정한 계정·과목·주차/과제 snapshot이다. 모든 자료의 검토 상태(사용 가능·누락·일부만 읽음)와 hash를 남긴다. 예산 초과나 읽을 수 없는 파일을 조용히 잘라 전체 검토했다고 표시하지 않는다. 과제 안내 누락은 생성을 막고 다른 자료 누락은 사용자에게 명시한 뒤 검토할 수 있다. 생성 결과의 출처 ID는 실제 읽은 snapshot 항목만 허용한다. 출처 ID 검증이 내용의 사실성을 보증하지는 않는다.

결과는 실행별 새 폴더에 저장한다. 원본 변경·삭제 없음. 경로는 모델 출력에서 받지 않는다. 계정 변경/취소는 후속 외부 전송과 완료 저장을 막는다. 재시작 시 실행 중 작업은 interrupted로 다루며 자동 재실행하지 않는다. 이미 발생한 API 비용은 취소로 환급되지 않는다.

수용 검사: 주차 범위, 과제 누적 자료 범위, 안내 누락/첨부 누락/길이 초과, 잘못된 출처, HTML/XML 주입, 중복 실행, 미설정 인증, 401/429/응답 손상, API timeout/취소, 렌더 실패, 실제 PPTX→PDF 변환·글꼴/쪽넘김, MP4 영상·음성 재생. 앱 연결과 실제 엔진 검사 전 기능 완료 아님.
