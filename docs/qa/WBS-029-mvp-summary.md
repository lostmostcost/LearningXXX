**결함 D-1 (REQ-004) — WBS-060에서 수정(PR #87), 11-04 재검수 통과.** 기록 없는 예전 대화의 복구(같은 대화 폴더의 Claude Code 세션 찾기)는 단위 테스트로 확인했고, 복제 데이터에서는 Claude Code 기록 위치가 원래 경로라 재현할 수 없어 실제 앱에서 예전 대화를 열어 확인해야 한다. 원래 내용: 채팅 화면에서 시작한 대화는 재개용 세션 기록(`.learningxxx-session.json`)이 만들어지지 않는다. 이 기록은 `conversation-service.ts`의 SDK `SessionStart` 훅과 고급 터미널(`native-terminal.ts`)에서만 쓰는데, 지금 Claude Code(2.1.317)는 채팅 실행에서 이 훅을 부르지 않는다(대화 기록에 UserPromptSubmit 훅만 있음). 그래서 고급 터미널을 한 번도 열지 않은 대화는 재시작하면 모두 이어지지 않는다. 실제 앱 데이터에서도 채팅 대화 5개 중 4개에 이 기록이 없다. 소유자가 앞서 말한 "재실행 후 채팅 기록이 사라짐"과 같은 현상이다. 원본 Claude Code 기록과 `.chat-ui.json`은 남아 있어 고치면 다시 열 수 있다. 수정 방향: 스트림 메시지의 `session_id`를 받는 즉시 기록을 쓰고, 재개 판단은 `getSessionInfo(id, { dir })`로 한다. 수정은 **WBS-060**(P0)으로 분리했다.
