## 4. 경계

- 기존 녹음 가져오기는 사용자 파일만 다룬다. **khu-lecture-recorder 스킬은 열거나 읽거나 참고하지 않는다.** 가져온 폴더의 코드 파일(.py 등)은 읽지 않는다. 녹음·전사·강의 내용은 저장소에 넣지 않는다.
- AI 처리(가독성 정리, 안내 추출, 번역)는 사용자가 요청할 때만, 공식 Claude Code CLI 구독 로그인으로. API 키 대체 없음. 결과는 원본과 따로 저장해 언제든 원본으로 돌아간다.
- 실행 시 자동 수집은 이 Mac에서 사용자의 로그인으로만, 서버 없음. 실패해도 앱 사용을 막지 않고 상태 줄에 알린다.
