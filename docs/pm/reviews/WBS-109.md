## 사용자에게 제공되는 흐름과 데이터

`node apps/desktop/host/scripts/app-control.mjs`를 시작하면 Mac의 숨김 renderer에서 현재 화면과 컨트롤 ID를 JSON으로 받는다. ID를 사용해 메뉴→과목→주차→자료→대화 생성→입력→전송을 수행한다. 각 단계의 확인·오류 상태를 읽고 다음 명령을 결정한다. 기본 fixture 응답은 합성이며 실제 Claude를 호출하지 않는다. local에서는 실제 router/서비스를 쓰지만 OS 파일 선택·마이크·학교 로그인 등은 별도 실제 앱 검증 경계로 멈춘다.

PNG는 동일 React/CSS 콘텐츠이며 창 테두리·OS 대화상자를 재작성하지 않는다. 넓은 PDF/채팅과 좁은 채팅 PNG를 실제 열어 내용·배치를 확인했다. 원본/쿠키/계정/강의 자료를 읽거나 저장소에 넣지 않았다. 증거는 각 실행이 출력한 비공개 임시 경로에 있고 저장소 커밋 대상이 아니다. 기본 프로필은 종료 시 삭제하고 `--profile`로 명시한 전용 프로필은 재시작용으로 남는다. 실패 후 자동 재생하지 않으며 snapshot과 저장 상태를 먼저 확인한다.

debug/assist 구분의 근거: 기본 debug 사용자 여정 통과와 단축 거부; 명시 assist의 catalog→과목/자료/메모 탭 직접 이동·오류 복구·증거 라벨 통과; local assist의 실제 IPC·모달·native 경계·테마 재시작 통과. 일반 입력은 maxlength도 우회하지 않는 별도 DOM 회귀로 확인했다.

## 남는 제한·후속 개선

- 마이크·macOS 권한창·학교 로그인·실제 구독 대화·실제 과제 제출·전사 품질의 재검증은 미실행이다. native 경계는 UI가 없는 CLI로 성공을 흉내내지 않는다. 실제 전송이 이미 진행 중일 때의 서버 동작을 로컬 계정 검사로 되돌릴 수는 없다.
- 드래그 전용 위젯·OS 대화상자·임의 contenteditable·iframe 내부를 모두 조작하는 범용 데스크톱 자동화 도구는 아니다. 현재 앱의 input/textarea/select/PDF/키보드 흐름을 지원한다. 도구 너비는 앱이 제공하는 키보드 방향키로 조절할 수 있다.
- 실제 두 과목 영상 전환은 미실행이다. 수정한 상태 초기화와 UI 회귀 검사 범위를 실제 데이터 기능 검증으로 과장하지 않는다.
- P2 후속: 약 1.19MB eager UI 번들의 PDF/특수 도구 로딩 분리와 거대한 App/main 초기화 분할. 현재 동작/중요 데이터 경계를 바꾸는 큰 재작성은 성능 측정·별도 수용 조건 없이 섞지 않았다. 현재 build 성공을 막지 않는 경고라 이번 작업의 blocker는 아니다.
- 초기 문서의 일부 오래된 구현/독립 세션 설명은 이력이다. 현재 기준을 찾기 쉽게 desktop README의 이력 구분과 개발 가이드를 보강했다. 기존 snapshot 전체를 최신 명세로 덮어쓰지 않았다.
