## 4. 실제 대규모 입력 한도 처리

실제 과목은 전체 50만 자 한도를 초과해 모델 요청 전 명시 오류로 중단됐다. UI·IPC·서비스를 함께 재검토하고 초기 입력의 명시 선택을 추가했다. 필수 과제 안내 제외, 알 수 없는/중복 ID, 누락 동의 없는 선택은 모델 요청 전에 거절한다. 선택에서 뺀 자료의 텍스트는 모델에 보내지 않고 제외 사유만 남긴다. UI는 글자 수·한도를 선행 표시하고 입력 선택 변경 시 동의를 초기화한다. 기존 전체 주차 원본/전용 대화 범위를 축소하지 않는다.
