### 결함 원인과 수정 (WBS-043)
- 외부 폴더 중단: macOS 폴더 선택 창이 한글 이름을 분해형(NFD)으로, CLI는 조합형(NFC)으로 보내 같은 폴더를 다른 경로로 판단. 경로 비교를 NFC로 통일.
- 채팅 기록: 화면에만 있고 저장되지 않았음. 세션별 대화를 `data/transcripts/<세션>.json`에 저장하고 세션을 열 때 불러옴. 종료로 끊긴 답은 "중단됨"으로 표시.
- 과목 문맥: CLI의 `--restricted`가 작업 폴더의 CLAUDE.md를 읽지 않음(실제 CLI로 확인). 과목명·주차별 자료 목록을 `data/courses/<과목>/course-context.md`에 쓰고 과목 세션에만 `--append-system-prompt-file`로 전달. 독립 세션은 이 옵션 자체가 거부됨.
- 휴지통 목록: 목록을 읽을 때 파일이 지금 있는지 확인해 없으면 "지금 없음" 표시, 휴지통 버튼 숨김.

수정 후 재확인 필요: 6·5(과목 이름 질문)·8을 다시 해 본다.

## 직접 따라 할 시나리오 (15분 내외)

1. `run-app.sh`로 앱을 켜고 상단에서 과목을 고른 뒤 `수집 실행`. 끝나면 왼쪽 자료 목록에서 주차 PDF를 연다.
2. 영어 문장을 드래그로 선택 → 보기 상단 `영어 → 한국어`. 오른쪽 채팅에 번역이 온다. `쉽게 설명`도 한 번 눌러 본다.
3. `과목 세션 만들기` → 열린 PDF로 `자료 첨부: …` → `첨부 확인` → "이 자료 3쪽 요점 정리해줘" 보내기. 이어서 `화면 캡처`로 한 영역을 찍어 질문한다(캡처 창에서 Esc로 한 번 취소도 해 본다).
4. 앱을 완전히 끄고 다시 켠다. 같은 과목 세션을 골라 "방금 말한 요점 중 두 번째를 더 설명해줘" — 앞 대화를 기억하면 재개 정상.
5. `독립 세션 만들기` → "지금 무슨 과목 자료를 보고 있어? 앞에서 무슨 얘기 했어?" — 모른다고 답해야 정상. 과목 이름·자료 내용이 나오면 P0 결함.
6. 과목 세션에서 `외부 폴더 추가`로 빈 테스트 폴더를 고르고 "이 폴더에 notes.md로 요점 저장해줘". 변경 목록에서 파일 확인 → `이 실행 전으로 되돌리기` 또는 `휴지통으로`(확인 창 표시) 시험.
7. 답변 중 `취소`, Wi-Fi를 끈 상태에서 `수집 실행` → 안내 문구가 나오고 앱이 멈추지 않으면 정상.

결과는 위 표에 날짜와 한 줄로 적고, 문제는 재현 절차·기대/실제·심각도(P0 데이터 손실·세션 교차, P1 기능 오류, P2 우회 가능)로 남긴다.

## 기능별 작동 설명

### 수집·자동 로그인·과목 전환 (REQ-001)
- 결과: 수강 중인 과목의 강의 자료(Canvas 파일, LearningX 주차 PDF)가 Mac에 원본 그대로 쌓인다.
- 흐름: `수집 실행` → 세션이 만료됐고 학교 계정이 저장돼 있으면 한 번 자동 로그인 → Canvas에서 수강 과목 목록 → 과목마다 Canvas 파일·LearningX 모듈 조회 → 바뀐 것만 내려받아 해시 확인 후 저장 → 자료 목록 갱신.
- 실행 위치: 전부 이 Mac의 앱 프로세스. 서버 없음(ADR-002). Claude는 관여하지 않는다.
- 데이터: `~/Library/Application Support/@learningxxx/desktop-host/data/library`(원본·manifest), 로그인 정보는 같은 폴더의 `credentials.bin`(키체인 키로 암호화).
- 자동/수동: 수집은 사용자가 누를 때만. 자동 로그인은 그 수집 직전 1회만.
- 실패 복구: 비밀번호가 거부되면 다시 저장할 때까지 재시도하지 않음(잠금 방지) → 로그인 창으로 진행. 중간 실패는 이전 성공 상태 유지, 다시 누르면 바뀐 것만 받음.

### 자료 보기·번역·쉬운 설명 (REQ-002, REQ-004)
- 결과: 앱 안에서 PDF를 보고 선택한 문장을 번역·설명받는다.
- 흐름: 자료 선택 → 호스트가 해시 재확인 후 바이트 전달 → 화면에서 렌더 → 문장 선택 → 버튼 → 선택 문장과 지시문만 담아 현재 세션으로 전송.
- 실행 위치: 렌더링은 앱 화면, 번역은 이 Mac의 공식 Claude Code CLI(본인 구독 로그인).
- 실패: 스캔 PDF는 "선택할 텍스트 없음" 안내. 세션이 없으면 버튼이 꺼져 있다.

### 첨부·캡처 채팅 (REQ-003)
- 결과: 과목 자료, 로컬 파일, 화면 일부를 질문에 붙인다.
- 흐름: 첨부 선택 → 호스트가 세션 전용 폴더에 복사본을 만들고 미리보기 → 사용자가 `확인` → 확인한 것만 CLI에 `--add-dir`로 전달.
- 데이터: `data/attachments/staged`(확인 전) → 실행 때 `attachments/runs/<실행>`으로 고정. 원본 자료는 바뀌지 않는다.
- 자동/수동: 확인하지 않은 첨부는 전송되지 않는다. 최대 8개.
- 실패: 캡처 취소·권한 거부는 그 첨부만 실패 표시, `다시 캡처` 가능.

### 세션 재개 (REQ-005)
- 결과: 과목별로 대화가 이어진다.
- 흐름: 앱 세션 ↔ CLI 세션 ID를 `data/app-state.json`에 저장 → 다음 질문에 `--resume`.
- 실패: 답변 중 앱이 꺼지면 그 실행은 "중단됨"으로 표시하고 자동 재전송하지 않는다. 그때까지의 파일 변경 기록은 남는다.

### 독립 세션 (REQ-006)
- 결과: 아무 문맥 없는 대화.
- 격리 방식(문구가 아니라 실행 조건): 과목 이름 없는 `data/sessions/<UUID>` 작업 폴더, CLI를 `--restricted --safe-mode --strict-mcp-config --disable-slash-commands`로 실행(메모리·CLAUDE.md·MCP·과목 폴더 미접근), 과목 ID를 받는 필드 자체가 없음. 직접 첨부한 것만 전달.

### 허용 폴더 작업·되돌리기·휴지통 (REQ-005)
- 결과: AI가 세션 작업 폴더와 사용자가 추가한 외부 폴더 안에서만 파일을 만들고 고친다.
- 흐름: `외부 폴더 추가`(그 세션에만 쓰기 허용) → 실행 전후 스냅샷으로 변경 목록 기록 → `이 실행 전으로 되돌리기` 또는 파일별 `휴지통으로`(호스트가 경로를 보여 주고 다시 확인).
- 실패: 바깥 경로 접근은 도구 단계에서 거부·표시. 영구 삭제는 하지 않는다.
