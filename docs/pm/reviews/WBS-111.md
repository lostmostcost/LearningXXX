## 단계별 자체 리뷰와 수정

1. **배치·문맥 모델**: layout.ts와 screen-context.ts, 기존 F6/리사이즈 호출자를 검토했다. 독립 토글과 좁은 도구 열의 실제 표시를 같은 panel 목록에서 산출한다. 사용하지 않는 이전 visiblePanels/NarrowView 및 우측 탭 CSS를 제거해 낡은 화면 모델이 검증 기준으로 남지 않게 했다. 새 순수 모델과 실제 사용자 흐름을 각각 확인한다.
2. **앱 연결·생명주기**: App.tsx 전체 변경과 RichChatPanel, RecordingPanel/MediaLibrary/TranscriptPanel 호출자를 대조했다. 화면 문맥 설계는 사용자 요청대로 읽기 전용 추가 에이전트와 상의했다. 닫을 때 RichChatPanel을 해제하면 초안/대기 첨부/작업 상태가 사라질 수 있어 전역으로 한 번 mount하고 숨김만 전환한다. 녹음은 기존 singleton과 같은 컴포넌트를 사용한다. 홈에서 보이지 않는 PDF도 유지해 현재 쪽을 잃지 않게 하고, 채팅/메모/열람 기록에는 실제 화면의 resource만 노출한다.
3. **잘못된 문맥·경로 수정**: 이전 selected assignment가 녹음/정보 화면에서도 과제 세션 범위를 활성화할 수 있었다. 실제 과제/자료 화면에 한정했다. 과목 요약/영상 상태가 다른 화면에 영향을 주지 않도록 실제 화면 조건을 적용했다. PDF 쪽·첨부·LMS 배지가 다른 화면에 남지 않도록 같은 visibleEntry 조건을 사용한다. 과제/공지 화면의 주차 메뉴에서 다른 종류 자료를 고르면 그 자료를 보여 주는 화면으로 이동한다. 일반/다른 과목 대화에는 현재 과목 viewing을 보내지 않는다. 화면 이동으로 새 세션 생성·기존 소속 변경·본문 자동 첨부는 추가하지 않았다.
4. **메모 저장·전환**: 기존 MemoPanel의 과목/주차 변경 중 늦은 get/save 응답이 새 scope의 text/base를 덮을 수 있었다. scope별 editor identity로 분리하고 로딩 완료 전 편집을 막았다. 저장을 직렬화해 앞 응답의 base를 다음 저장에 사용하고 flush는 진행 중 저장도 기다린다. get 실패 시 재불러오기를 제공하며 기존 optimistic conflict 안내는 유지한다. 실제 UI에서 두 주차의 텍스트가 분리되고 돌아올 때 저장본이 복원되는 것을 확인한다.
5. **CLI·시각 리뷰**: host/renderer의 assist parser를 함께 media에 맞췄다. tab만 여는 assist는 현재 화면을 유지하고 과목 미선택에서도 동작하게 했다. debug 단축 거부·stale target/비활성 쪽 경계는 유지한다. 스모크는 각 클릭 직전에 snapshot을 새로 관찰하며 거부된 동작을 자동 재생하지 않는다. 초기 검사에서 stale 핸들 거부가 실제 발생해 이를 우회하지 않고 관찰 시점을 수정했다. 리사이저는 저장 요청값이 CSS 최대치로 줄어든 경우 실제 표시 너비에서 키보드 조절하도록 고쳤다. 배경 PNG에서 자료+채팅/두 도구/녹음·전사/좁은 화면을 열어 확인했고, 활성 토글 글자 색·좁은 개발 빌드 표식·가용 콘텐츠 너비와 미디어 단일 열을 보완했다.

각 단계에서 실제 diff와 관련 호출자/경계·오류/화면 전환을 다시 검토하고 해당 타입/모델/CLI 검사를 실행했다. 최종 통합은 `4a39bbe` 대비 전체 변경과 allowlist를 다시 확인한다. 재리뷰에서 위 수정 범위의 추가 수용 차단 결함은 발견하지 않았으며 모든 제품 동작이 무결함이라고 주장하지 않는다.

## 기능 설명·수동 경계·후속

Mac 로컬 앱에서 좌측 마이크 아이콘(녹음·전사)을 누르면 녹음 제어와 기존 원본/전사를 한 화면에서 본다. 자동 전사는 기존 로컬 엔진·큐·파일을 사용하며 시작/정지와 원본 선택은 사용자가 한다. 상단 채팅/메모는 기본 닫힘, 각각 토글 가능하며 동시에 열면 우측 위아래로 구분된다. 좁은 창은 열린 도구가 콘텐츠 영역을 쓰며 상단 버튼으로 모두 닫아 복귀한다. 메모는 기존 과목/주차 파일에 자동 저장하고 버전 충돌/읽기 실패를 표시한다. 저장 실패·충돌 시 표시된 원인을 확인하고 재불러오기 또는 내용을 보존한 뒤 재시도해야 하며 성공으로 표시하지 않는다.

채팅의 현재 화면 표시는 자동 갱신하고 대화 소속은 보존한다. 자동 세션 분리·재배정, 자료 본문 자동 첨부와 host 문맥 확장은 후속 사용자 협의 사항이다. 실제 Claude 호출·학교 로그인/과제 제출·마이크 권한·실음 녹음·전사 엔진 실행/품질은 이번 합성 레이아웃 검증으로 입증하지 않는다. 녹음 지속은 기존 singleton 경로와 회귀 검토 범위이며 실제 마이크를 켰다고 기록하지 않는다. 사용자의 실제 앱 세션/계정 자료를 열거나 대화를 전송하지 않았다.
