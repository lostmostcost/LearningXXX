# ADR-003 · STT 엔진·실행 위치·전사 개선 (WBS-021)

- 상태: 결정 (이문찬, 2026-11-02 "qwen으로 정하고 다음 단계 진행")
- 요구: REQ-007, REQ-008 · SPEC-004 "엔진·비용·위치"
- 근거: [spikes/stt/README.md](../../spikes/stt/README.md) 실험

## 결정 1. 엔진: Qwen3-ASR 1.7B (MLX, 로컬)

- 기본 엔진은 Qwen3-ASR 1.7B를 Apple Silicon에서 MLX(`mlx-qwen3-asr`)로 실행한다. 라이선스 Apache 2.0.
- 이유: B 단계 핵심인 대면 녹음에서 whisper.cpp보다 뚜렷이 정확했다. 온라인 강의는 둘 다 충분했다.
- 비용: 10분 녹음당 약 2.5~3.5분(타임스탬프 포함 약 4~5.5분), 최대 메모리 약 4GB, 디스크 약 6GB. 전사는 녹음·다운로드 후 자동으로 백그라운드에서 돌므로 수용한다.
- 메모리가 작은 Mac(8GB)은 8bit 또는 0.6B를 쓴다. 선택 기준은 WBS-025에서 실측해 정한다.
- 타임스탬프는 함께 공개된 Qwen3-ForcedAligner로 단어 단위를 얻어 구간으로 묶는다.
- whisper.cpp large-v3-turbo는 채택하지 않는다(대체 경로로도 지금은 만들지 않음). 실험 스크립트는 남긴다.

## 결정 2. 실행 위치와 전송: 각자의 Mac, 외부 전송 없음

- 전사는 녹음이 있는 Mac 안에서만 실행한다. 녹음 원본을 외부 STT 서비스로 보내지 않는다. 유료 STT·API 키는 쓰지 않는다.
- Python 런타임은 시스템이 아닌 앱 전용 가상환경(앱 데이터 폴더 아래)에 두고, host가 별도 프로세스로 실행한다. 모델은 첫 사용 때 받는다.

## 결정 3. 전사 개선은 세 단계, 원본 엔진 출력은 그대로 보존

1. **엔진 단계(자동)**: 과목 자료(.pdf.txt)와 자료 제목에서 뽑은 용어를 `--context`로 넘긴다. 침묵은 엔진의 저에너지 분할에 맡긴다.
2. **규칙 정리(자동)**: 반복 문장·알려진 환각 문구 제거, 단어 타임스탬프를 읽기 좋은 구간으로 묶음.
3. **Claude 보정(요청 시)**: 사용자가 "전사 다듬기"를 누를 때만 구독 CLI로 강의 자료를 참고해 용어·오타·문장부호를 고친 보정본을 별도 버전으로 만든다. 구간 단위로 고쳐 타임스탬프를 유지한다. 원본 엔진 출력은 지우거나 덮어쓰지 않는다.

## 미검증·후속

- 사람 기준 전사로 잰 CER(대면 녹음): WBS-028 자가 테스트에서 기록한다.
- 8GB Mac 메모리·속도: WBS-025.
- Apple SpeechAnalyzer는 시험하지 않았다. Qwen이 막히면 다음 후보로 본다.
