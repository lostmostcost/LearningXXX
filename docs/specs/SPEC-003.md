## 화면 원칙
REQ-003/006/009. 자료를 읽는 화면과 자유 채팅이 중심이다. CR-047(2026-11-03 사용자 직접 승인): 시작 화면은 실제 수집 과목·과제 일정·개인 할 일 대시보드다. 과목 선택 후 PDF·채팅 중심 화면으로 전환한다. 초기 이미지 시안은 참고이며 최신 회의의 자유 채팅 결정을 따른다.

## 정보 구조 제안
왼쪽: 상시 목적별 아이콘 레일 + hover/focus/클릭으로 펼치는 과목 목록과 고정 토글. 상단 주차 자료 트레이는 hover/focus/클릭으로 접근한다. 중앙: 선택 자료 원본 뷰어와 텍스트 선택. 오른쪽: 채팅/녹음 선택 탭. 각 화면은 탭 전환 중 유지되며 녹음을 중단하지 않는다. 세션 목록은 선택 바를 누르면 펼쳐지며, 바깥 클릭·Escape·세션 선택으로 닫힌다. CR-048(2026-11-03 사용자 직접 승인): 수집·로그인 설정·앱 수정·세션 조작은 SVG 아이콘과 툴팁·접근성 이름을 사용한다. 확인·오류·보안 경계 안내는 명시적으로 유지한다. 작은 창에서는 자료/채팅 전환을 제공한다. 상단에는 수집 상태와 현재 과목·세션·독립 모드 표시를 둔다. 빈 화면은 수집 실행 방법과 수동 첨부 경로를 안내한다.

## 주요 사용자 여정
1. 앱 실행 → 수집 결과 확인 → 주차 자료 열기.
2. 텍스트를 선택해 번역 또는 쉬운 설명을 요청한다. 선택 범위와 원문 위치가 질문에 연결된다.
3. 채팅 입력창의 첨부 버튼으로 자료/로컬 파일을 선택하거나 캡처 버튼으로 원하는 부분을 넣는다.
4. 전송 전 포함된 입력을 확인한다. 답변에 가능한 경우 원본 파일·페이지·구간 참조를 연결한다.
5. 과목 안에서 별도 세션을 만들고 이름을 바꾸거나 보관한다. 독립 세션은 빈 문맥 상태를 눈에 띄게 표시한다.
6. 요약·공부 계획·과제 보조는 자연어 요청으로 실행하고 결과를 저장할 때만 산출 파일을 만든다.

## 입력과 응답 계약
ComposerDraft: text, attachmentIds[], selection{assetId, page?,start?,end?,text}?, captureIds[], targetSessionId.
전송 시 세션과 첨부가 고정된다. 실행 중 다른 자료를 열어도 이미 보낸 입력이 몰래 바뀌지 않는다. 첨부 제거는 전송 전만 영향을 주고 과거 메시지 이력은 보존한다. unsupported 문서는 원본 열기와 지원 형식 안내로 처리한다. OCR·모든 Office 형식 지원을 자동 범위 확대하지 않는다.
MVP 번역은 사용자 결정으로 영어 ↔ 한국어를 지원한다. 선택 텍스트의 번역 방향을 영어→한국어 또는 한국어→영어로 지정하며 ‘쉬운 설명’은 별도 기능으로 유지한다. 생성 답변은 검증된 강의 정답인 것처럼 표시하지 않는다.

## UI 상태와 복구
전송 대기/응답 중/취소/권한 요청/오류/사용량 제한을 구분한다. 실패 재시도는 같은 요청 재전송 여부를 사용자에게 드러낸다. 첨부 준비 중에는 전송 버튼을 잠그고 파일별 실패를 보여준다. 캡처 취소는 채팅을 전송하지 않는다. 자료 다운로드 중 기존 자료는 계속 읽을 수 있다.
키보드로 과목·자료·입력창 이동, 선택 상태, 명료한 버튼 이름을 제공한다. 원문 뷰어 확대와 패널 크기 변경을 지원하는 방향으로 구현한다.

## 지원 형식 결정
WBS-003의 사용자 결정으로 A 단계 문서 지원은 PDF 우선으로 확정했다. 대상은 2026학년도 2학기 논리회로(Canvas 95899)이며 공개된 주차별 PDF 18개를 초기 검수 표본으로 사용한다. PDF 텍스트 추출 불가, 암호 문서, 스캔본은 별도 상태로 표시한다. PPT/Word/HWP는 필요 근거와 변환 품질을 확인하고 추가한다.

## 수용 시나리오
질문이 어떤 자료·선택·캡처를 포함하는지 전송 전에 알 수 있다. 세션 변경 중 오발송되지 않는다. 선택 번역은 선택하지 않은 문서 전체를 임의 첨부하지 않는다. 답변을 읽고 관련 원문으로 돌아갈 수 있다. 독립 세션에서 과목을 열어두어도 자동 첨부되지 않는다. 요약은 요청 없이 백그라운드로 생기지 않는다.


## CR-049 · 문서·답변·명령 탐색
사용자 직접 승인(2026-11-03). PDF는 기본 페이지 맞춤과 연속 수직 스크롤, 트랙패드 pinch(ctrl+wheel) 확대/축소를 제공한다. 커서 위치를 기준으로 확대하고 화면 근처 페이지만 렌더한다. 선택·현재 페이지·스냅샷은 실제 페이지 번호에 연결한다. 실제 Mac 트랙패드 동작은 별도 확인이 필요하다.
AI 답변은 Markdown(굵게·목록·표·코드)으로 렌더한다. raw HTML·로컬 링크·외부 이미지 자동 로딩은 허용하지 않는다. / 입력은 필터 가능한 목록과 방향키·Tab/Enter 선택을 제공한다. /help, /clear(기존 대화 보존 후 같은 모드 새 세션), /resume, /rename, /status는 앱 로컬 동작이다. CLI 비대화형과 터미널 명령은 다르며 /compact·/model 등 미지원 명령은 실행 불가 이유를 표시한다. 전체 CLI 명령 호환은 실행 구조 결정 대기이며 이번 구현 완료로 간주하지 않는다. 기존 구독 로그인·독립 문맥 격리 정책은 유지한다.

## CR-050 · Claude Code 중심 채팅
새 채팅의 기본 화면은 실제 CLI 터미널이다. 입력 / 목록·자동완성·권한·답변은 설치된 Claude Code가 표시한다. 앱이 제공하던 로컬 명령 제안은 이전 structured 채팅 화면에만 남는다. 일반 대화는 격리 없음 안내를 표시한다. 사용자 초기화 승인에 따라 기존 대화 기록 이전·호환 화면은 제공하지 않는다.
PDF 선택 문장은 명시 복사 후 CLI 입력창에 붙여넣는다. 파일/PDF는 준비→사용자 확인→읽기 전용 전달 복사본 경로 복사→원하는 CLI 대화에 사용자가 붙여넣는다. 키 입력을 권한 확인 화면에 잘못 주입할 수 있어 파일/선택을 자동으로 타이핑·전송하지 않는다. 녹음 탭과 세션 선택을 바꿔도 같은 CLI 프로세스는 유지한다.
