# 과제 전용 작업공간 (WBS-097)

CR-093 / SPEC-006 v0.2.0 / REQ-003·004·009·013. 퀴즈는 대상이 아니다. 실제 LMS 제출은 별도 WBS-058이며 이번 기능이 자동 제출하지 않는다.

1. 수집된 과제를 열면 가운데에 **과제 안내 / AI 제출용 초안 미리보기**, 오른쪽에 **과제 전용 · 전체 주차** 채팅이 나온다. 일반 대화의 선택과 입력 초안은 유지된다.
2. 초안 탭에서 초기 생성 입력의 읽을 수 있는 텍스트·누락·글자 수를 확인한다. 전체 50만 자를 넘으면 자료 이름을 검색하여 필요한 입력을 명시적으로 선택한다. 과제 안내는 제외할 수 없다. 누락/제외가 있으면 부분 생성 확인을 선택해야 한다. PDF 텍스트 추출은 그림·도표를 검토한 것이 아니다.
3. **AI 초안 만들기**는 기존 공식 Claude Code 구독 runner로 구조화된 초안을 생성한다. 본문과 필요한 도표를 검증하여 로컬 HTML 작업 사본에 저장한다. 한도/형식/출처 검증 실패, 취소, 앱 종료 뒤 유료 요청을 자동 재실행하지 않는다. 이전 초안은 보존된다.
4. 오른쪽 과제 채팅에서 작성을 요청하거나 기존 초안을 수정한다. 해당 계정·과목·과제의 별도 세션이며 같은 과목의 모든 주차 원본·쪽별 텍스트·전사·메모 사본을 읽을 수 있다. 일반 Claude Code 환경과 전역 설정·기억을 사용하는 승인된 native 세션이다. 격리된 세션이라고 보지 않는다. 권한 확인은 사용자가 직접 처리한다.
5. 채팅이 `outputs/assignment-draft.html`을 고치면 잠시 안정된 내용을 새 판으로 보존하고 **최신 판 · 실시간** 미리보기를 갱신한다. 과제·과목 전환은 이미 보낸 요청의 대상을 바꾸지 않는다. **새 과제 대화**는 마지막 수정본과 과거 판을 남기고 새 세션에서 이어간다.
6. 보존 판을 골라 **이 판을 PDF로 만들기**를 누른다. 출력은 선택한 판에 고정되므로 그동안 새 채팅 수정이 생겨도 섞이지 않는다. **PDF 열기 / Finder에서 보기**로 결과를 확인한다. 실제 제출 전 내용·ERD·한글·쪽 나눔을 확인해야 한다.

로컬 데이터는 기존 userData의 `data/assignment-workspaces`와 `data/native-sessions` 아래에 저장한다. HTML 판은 hash로 확인하고 생성별 `.generation.json`에는 제공 텍스트의 hash·출처 ID·명시 누락 범위를 남긴다(본문 복제 없음). 원본 수집 자료를 수정하지 않는다. 판은 최대 2,000개이며 한도에서는 이전 판을 지우지 않고 추가 저장을 멈춘다.

미리보기는 별도 `assignment-preview:` origin의 sandbox iframe으로 표시하며 스크립트·외부 자원·폼을 허용하지 않는다. PDF는 JavaScript와 네트워크·권한이 차단된 일회성 Electron session에서 로컬 출력한다. renderer가 임의 파일 경로를 지정할 수 없다. 계정 변경·심볼릭 링크·보존 파일 변조는 거절한다. native Claude 자체의 일반 환경 권한과 앱의 파일/계정 경계는 서로 다른 사항이다.

복구: 입력이 바뀌면 **자료 다시 읽기** 후 범위와 부분 생성 확인을 다시 선택한다. 연결이 끊기면 채팅의 **다시 연결**을 사용하고, 이전 전송 기록을 먼저 확인한다. 앱이 중단되면 과제를 다시 열어 보존 판을 확인한 뒤 직접 다시 생성/출력한다. PDF 발행 직후 index 기록 전에 중단된 경우도 동일 판을 다시 출력할 수 있다.

검사 명령과 실제 수행 결과·남은 제한은 `docs/pm/reviews/WBS-097.md`에 기록한다. 합성 상태 테스트의 `%PDF-` 바이트는 실제 PDF 품질 검증을 대신하지 않는다.
