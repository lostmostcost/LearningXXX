# YOLO UNIV v1.0.0 — 공모전 제출 버전

- 날짜: 2026-11-04
- 태그: `v1.0.0` (WBS-099)
- 대상: Apple Silicon Mac, macOS 13 이상
- 포함 범위: 2026-11-04 main까지 병합된 기능(WBS-098 UI 간소화, WBS-099 macOS 표준 둥근 앱 아이콘, WBS-100 라이트·다크 테마 전환까지). 초안 상태인 WBS-092(주차 영상·과제 PPT 연결)와 보류된 WBS-058(과제 제출)은 들어 있지 않습니다.

## 받는 파일

GitHub Release `v1.0.0`에 아래 파일이 올라갑니다. 체크섬은 같은 Release의 `SHA256SUMS.txt`에 있습니다.

| 파일 | 용도 |
|---|---|
| `YOLO-UNIV-1.0.0-arm64.dmg` | 열어서 `YOLO UNIV`를 `Applications`로 끌어다 놓는 설치 이미지 |
| `YOLO-UNIV-1.0.0-arm64.zip` | 같은 앱을 압축한 파일. 풀면 `YOLO UNIV.app` 하나가 나옵니다 |

앱 하나에 화면, Mac 쪽 실행 코드, PDF 처리, 과제 초안 엔진, 전사 엔진 설치 스크립트, 필요한 라이브러리가 모두 들어 있습니다. 소스 폴더나 pnpm, Node가 따로 필요하지 않습니다.

## 설치와 처음 실행

1. `.dmg`를 열고 `YOLO UNIV`를 `Applications`로 끌어다 놓습니다.
2. 이 앱은 Apple 개발자 인증서가 아니라 ad-hoc으로 서명돼 있어서(공증 없음), 인터넷에서 받은 앱을 처음 열 때 macOS가 막습니다. 다음 중 하나로 엽니다.
   - Finder에서 앱을 한 번 열어 본 뒤 **시스템 설정 → 개인정보 보호 및 보안**에서 **그래도 열기**를 누릅니다.
   - 또는 터미널에서 격리 표시를 지웁니다.

     ```sh
     xattr -dr com.apple.quarantine "/Applications/YOLO UNIV.app"
     ```
3. **Claude Code**를 설치하고 한 번 로그인해 둡니다(`claude` 실행 후 구독 로그인). 앱은 `~/.local/bin/claude`, `~/.claude/local/claude`, `/opt/homebrew/bin/claude`, `/usr/local/bin/claude` 순서로 찾고, 본인 구독 로그인만 씁니다. API 키는 쓰지 않습니다.
4. 앱을 켜면 “학교 로그인” 창이 열립니다. 본인 Mac에서 직접 LMS에 로그인한 뒤 **수집 실행**을 누르면 수강 과목이 들어옵니다.
5. 자동 전사를 쓰려면 녹음·전사 화면의 **전사 엔진 준비**를 한 번 누릅니다. `uv`나 Python 3.10 이상이 필요하고(`brew install uv`), 엔진과 모델은 앱 데이터 폴더 안에만 설치됩니다.
6. 화면 테마는 상단 바의 해/달 버튼으로 라이트·다크를 바로 바꾸고, 설정(사람 아이콘) → **화면 테마**에서 “시스템 설정 따르기”로 되돌립니다. 선택은 이 Mac에 저장돼 다시 켜도 유지됩니다.
7. 녹음과 화면 캡처를 처음 쓸 때 macOS가 마이크·화면 녹화 권한을 묻습니다. 개발 버전으로 허용했던 권한은 새 앱에 이어지지 않으니 다시 허용합니다.

## 데이터 위치, 백업과 복구

- 모든 자료·녹음·전사·대화·설정은 `~/Library/Application Support/@learningxxx/desktop-host/`에 있습니다(`data/`, `credentials.bin`, `stt/`). 개발 실행과 같은 폴더라서, 전에 소스로 쓰던 자료가 그대로 보입니다.
- 저장된 학교 로그인 정보는 키체인 키로 암호화돼 있습니다. 새 앱이 처음 키체인을 읽을 때 접근을 묻는 창이 뜨면 **항상 허용**을 누릅니다. 거절하면 학교 로그인을 다시 저장하면 됩니다.
- 백업: 앱을 종료한 뒤 위 폴더를 통째로 복사합니다. 전사 엔진(`stt/`)은 크기가 크고 다시 설치할 수 있으니 빼도 됩니다.
- 복구: 앱을 종료하고 복사해 둔 폴더를 같은 위치에 되돌립니다. 앱 자체가 망가지면 `.dmg`에서 다시 설치하면 되고, 데이터 폴더는 건드리지 않습니다.
- 삭제: 앱을 휴지통으로 옮기고, 데이터까지 지우려면 위 폴더를 지웁니다.

## 직접 빌드하기

```sh
pnpm install --frozen-lockfile
node infra/release/build-mac-app.mjs
```

결과는 `build/release/`에 생깁니다(`YOLO UNIV.app`, `.dmg`, `.zip`, `SHA256SUMS.txt`). 스크립트가 하는 일:

1. UI(Vite)와 host(esbuild)를 빌드합니다.
2. `pnpm deploy --prod`로 lockfile 그대로의 실행용 라이브러리만 받습니다. Claude Agent SDK에 딸린 Claude 실행 파일(약 240MB)은 넣지 않습니다. 앱은 언제나 사용자가 설치한 Claude Code를 쓰기 때문입니다.
3. 저장소와 같은 폴더 구조로 `Contents/Resources/app`에 넣고, 실행 코드가 부르는 외부 모듈이 모두 앱 안에서 찾아지는지 검사합니다.
4. `@electron/packager` 20.3.0(build 폴더 안에만 설치)으로 Electron 44.9.0 앱을 만들고, 번들 ID `io.github.lostmostcost.yolouniv`, 버전 1.0.0, 아이콘, 마이크 사용 설명을 넣습니다.
5. ad-hoc 서명 후 `codesign --verify --deep --strict`로 확인하고 `.dmg`와 `.zip`을 만듭니다.

## 알려진 한계

- **공증되지 않음.** Developer ID 인증서가 없어 처음 열 때 위 2번 과정이 필요합니다.
- **Apple Silicon 전용.** Intel Mac용 빌드는 없습니다.
- **앱 수정 기능(WBS-031)은 소스 실행에서만** 동작합니다. 배포 앱은 git 소스 폴더가 아니어서 앱 수정 요청을 받지 않습니다.
- 자동 업데이트가 없습니다. 새 버전은 새 `.dmg`로 덮어 설치합니다(데이터는 유지).
- 전사 정확도와 8GB Mac에서의 속도는 아직 측정하지 않았습니다. 기능별 알려진 문제는 [MVP 정리](../qa/WBS-029-mvp-summary.md)에 있습니다.
- 경희대 LMS 한 곳만 지원하며, 경희대학교의 공식 서비스가 아닙니다.

## 이 버전에서 확인한 것

- 빌드: `node infra/release/build-mac-app.mjs` 성공. `.app` 451MB, `.dmg` 194MB, `.zip` 180MB.
- 번들: 실행 파일·도우미 앱 이름이 `YOLO UNIV`, Info.plist 버전 1.0.0, 아이콘이 YOLO UNIV 아이콘, ad-hoc 서명 검증 통과(압축을 푼 뒤에도 통과).
- 실행: `.zip`을 저장소 밖 임시 폴더에 풀어, 빈 앱 데이터(`--user-data-dir`)와 최소 환경으로 실행. 창이 앱 안의 `Contents/Resources/app/apps/desktop/ui/dist/index.html`에서 열리고 “오늘의 학습” 화면이 그려짐. 화면 스크립트 오류 없음. `app.build`가 `{dev:false}`(배포 빌드), 과목 0개, 앱 수정 `sourceConfigured:false`, 학교 로그인 창이 자동으로 열림(로그인은 하지 않음).
- 앱 안의 라이브러리: 배포 앱의 Electron/Node로 Claude Agent SDK(`query`, 세션 함수), pdf.js(합성 PDF에서 글자 추출), pdf-lib, 과제 초안 엔진을 불러옴.
- 확인하지 않은 것: 실제 학교 계정 로그인·수집, Claude 대화, 녹음·전사, 다른 Mac에서 Gatekeeper를 거친 설치. 이 부분은 개발 실행과 같은 코드라 기능 차이는 없지만 배포 앱으로 직접 해 보지는 않았습니다.
